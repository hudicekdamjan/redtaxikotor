# Original photos

Drop original photographs here using these exact file names, then run `npm run images`.
Landscape orientation, at least 1600 px wide. Any of .jpg / .png / .webp works.

| File name | Used for |
|---|---|
| red-taxi-corolla.jpg | Main vehicle photo (home hero, about) — white Corolla, RED TAXI + number on rear doors |

| tivat-airport.jpg | Airport transfers |
| tivat.jpg | Tivat / Porto Montenegro (taxi services) |
| interior.jpg | Car interior (business / premium) |
| perast.jpg | Perast — Our Lady of the Rocks |
| perast-panorama.jpg | Excursion: Kotor – Panorama – Perast |
| sveti-stefan.jpg | Excursion / destination: Sveti Stefan |

| skadar.jpg | Excursion: Skadar Lake |
| budva.jpg | Excursion: Sveti Stefan – Budva – Perast |

If a photo needs an author credit, add `credit` to its entry in `src/config/images.ts`
(credits are shown automatically in the footer).
